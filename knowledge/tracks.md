# Ideas from the kickoff slide ("pick one, or combine them")

1. Graph ML: Mule network finder. Cluster wallets set up by one source; score the group, not each wallet.
2. Path tracking: Money trail tracker. Follow funds hop by hop through fresh wallets to the cash-out (usually an exchange).
3. Anomaly detection: Limit-dodge detector. Repeated payments just under limits, spread across linked wallets.
4. Pattern mining: Fake trading detector. Wallets trading in circles on the DEX/AMM to fake volume and prices.
5. Ranking: Alert ranker. Riskiest alerts first; learn from analyst close/escalate.
6. LLM: Case summary writer. Plain-English explanation per alert, each claim linked to a real transaction.

Note: only the score (AP) decides prizes. Ideas 1–4 feed features into the ranker; 6 is optional polish via the `reason` column.
